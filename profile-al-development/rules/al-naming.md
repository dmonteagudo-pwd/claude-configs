# AL Naming Rules

> Rules from a project overlay plugin (for example `profile-bc-prodware/rules/`) prevail over this file in any conflict.

This plugin sets no naming convention of its own. Follow the naming rule of the project or its overlay plugin: affix, prefix or suffix placement, object-name pattern and namespaces come from there. When no project rule exists, match the naming already used in the extension.

**AppSourceCop is the authority on affixes.** The registered affix is in `AppSourceCop.json`; fix every affix diagnostic it reports.
